# Drogaria Félix

Sistema de controle de estoque para drogaria, desenvolvido em Java e executado pelo terminal. Disciplina de Elicitação e Programação.

## Funcionalidades

- Mensagem de boas-vindas
- Cadastro de produtos (código, nome, categoria, preço, quantidade e exigência de receita)
- Listagem do estoque com todos os produtos cadastrados
- Menu que repete até o usuário escolher sair

## Conteúdos aplicados

- Tipos de dados, entrada e saída (`Scanner`)
- Operadores e expressões
- Estruturas condicionais (`if`, `else if`, `else`)
- Estruturas de repetição (`while`, `do while`)
- Vetores
- Classes, objetos, pacotes e métodos
